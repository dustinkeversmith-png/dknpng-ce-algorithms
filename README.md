# combinatorial

A C++20 framework for describing state spaces as typed flat memory, constraining
them with invariants, and searching them constructively. Two domain
applications sit on top: an instruction-level register machine with program
synthesis, and an N-qubit quantum state simulator.

```
TypeRegistry ─ owns ─▶ ValueType ─ describes ─▶ Value (flat bytes, zero-copy views)
                                                   │ verified & generated by
                                                   ▼
                    Invariant / Constraint ─▶ Space ─▶ Synthesizer
                                                   │
                       ┌───────────────────────────┴──────────────────────────┐
             automaton::Machine / TransitionSpace          quantum::StateSpace / Circuit
             ProgramSynthesizer                            gates, measurement, entanglement
```

## Build

Requires CMake ≥ 3.24, Ninja, a C++20 compiler (GCC 13 / Clang 18 tested),
GoogleTest and Google Benchmark (`apt install libgtest-dev libbenchmark-dev`).
z3 is optional; if found, the SMT round-trip tests run against it.

```bash
cmake --preset debug && cmake --build build/debug && ctest --preset debug
```

```bash
cmake --preset release && cmake --build build/release && ./build/release/bench/combinatorial_bench
```

```bash
cmake --preset asan && cmake --build build/asan && ctest --preset asan
```

Everything compiles with `-Wall -Wextra -Wpedantic -Werror`.

## Modules

| Module | Headers | What it does |
|---|---|---|
| `value` | `value/*.hpp` | Packed recursive layouts, row-major tensor strides, zero-copy element/member/path views, bitwise and numeric scalar casts, dynamic operator table |
| `problem` | `problem/*.hpp` | Invariant predicate trees, symbolic constraints with interval reasoning, SMT-LIB2 lowering, `Space` + set algebra, metrics, synthesizer, `ConstrainedSpace`, `BoxSpace` |
| `automaton` | `automaton/*.hpp` | 30-opcode register machine whose state is a `Value`, step invariants T(Sₜ, Sₜ₊₁), example-driven program synthesis |
| `quantum` | `quantum/Quantum.hpp` | `f64[2^N,2]` state Values, in-place gates, k-qubit contraction, measurement, purity, QFT/GHZ, circuit synthesis |

See [docs/architecture.md](docs/architecture.md) for the design and
[docs/guide.md](docs/guide.md) for worked examples.


```

  shl r1 r0 r1
  add r1 r0 r1

```

```bash
./build/release/tools/combi quantum --qubits 3 --circuit "h q0; cx q0,q1; cx q1,q2" --shots 1000
```

```bash
./build/release/tools/combi queens 8
```

```bash
./build/release/tools/combi run "movi r0 6; movi r1 7; mul r2 r0 r1; halt"
```

## Tests

* 101 GoogleTest cases across value, invariant/SMT, space/synthesis, automaton and quantum suites
* 6 fuzz harnesses (`fuzz/`): reference paths, type expressions, assembler, SMT models,
  raw machine words, and a value/quantum op-stream. They expose `LLVMFuzzerTestOneInput`
  and ship a standalone driver: `./build/asan/fuzz/fuzz_path --runs=1000000 --seed=7`
* 5 CLI smoke tests
