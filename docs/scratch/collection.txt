  Metric / Distance Function ($d(s_1, s_2) \to \mathbb{R}_{\ge 0}$):
   Computes distance between two different elements in the space
  
  Neighborhood / Mutation Operator ($\mathcal{N}: S \to \text{LazyList}[S]$):
	Defines the valid local perturbations from a given state without leaving structural bounds (e.g., swapping two elements, perturbing a matrix cell by $\pm \epsilon$).

  Projection / Clamping Operator ($\text{project}: S \to S$):
	Takes an arbitrary or out-of-bounds state and projects it back onto the nearest valid point in the space (crucial for constrained optimization or repair).

  Dimensionality / Cardinality Bounds:
	Explicit measure of the space's size: $\vert{}S\vert{}$ for discrete spaces or $\dim(S)$ for continuous spaces.
	
  Algebraic Combinators (Products & Direct Sums):
   Operations to compose spaces together (e.g., $S_1 \times S_2$ via Cartesian product, or $S^N$ via tensor/vector power).
